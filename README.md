The financial volatility prediction project 

collaborates with the fintech company Optiver, using high-frequency order book data to predict volatility.

Data cleaning + feature engineering (bid-ask spread, imbalance in trading volume, liquidity)
Comparing multiple time series + machine learning models(HAV,SVM,LR,RF)
Establish an evaluation system for rolling window predictions
Using R Shiny for the visualization platform


How to use:
Download all the files from both branches at the same time. 
(There are two datasets named "stock.RData" and "target.RData" in the dataset, 
but they are too large to upload. If needed, I can provide it.)
